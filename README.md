# Sivoov Run

Virtual race experiences for real races. Runners who could not get a bib run the race
distance anywhere during race week, with the race in their ears, and get an official
time, a certificate and the medal. Organizers sell entries to a sold-out demand.

- Web: https://run.sivoov.app
- Docs: start with `CLAUDE.md`, then `docs/STATUS.md`.

This repository was seeded from `arthur-flam/sivoov` (see `docs/HARVEST.md`).
